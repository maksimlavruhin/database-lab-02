# Лабораторная работа №2 · ALTER TABLE, SELECT и JOIN

Настольное приложение для учёта экспериментов по ИИ-модерации текста. В этой версии доступны функции предыдущих лабораторных.

## Запуск

Скачайте или клонируйте репозиторий и откройте его папку в терминале.

Нужны Python 3.12, запущенный PostgreSQL версии 13 или выше и роль с правом создавать схемы в выбранной базе. Для чистого запуска подойдёт локальная база `postgres` или отдельная учебная база. Дистрибутивы для macOS, Windows и Linux доступны на [сайте PostgreSQL](https://www.postgresql.org/download/).

**macOS и Linux**

```sh
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m lab02
```

**Windows PowerShell**

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m lab02
```

В окне приложения введите адрес, порт, имя базы, имя роли PostgreSQL и пароль. Адрес `localhost` и порт `5432` подходят для локального PostgreSQL со стандартными настройками.

1. Нажмите **Подключиться**.
2. Нажмите **Создать схему и таблицы**.
3. Нажмите **Добавить демонстрационные данные**.
4. Откройте **Показать данные** и выберите инструмент работы.

Приложение использует схему `moderation_lab2`. При стандартной структуре создание схемы и загрузку примеров можно повторять. Меняйте структуру в выбранной лабораторной. Если переименуете базовые таблицы или поля, верните исходные имена для дальнейшего использования сводки и готовых форм ввода.

Конструкторы выводят до 1000 строк. Загруженные результаты можно сортировать по заголовкам столбцов и фильтровать по тексту. Пароль вводится при подключении. События и ошибки записываются в `database-labs.log`.

## Возможности

- [Форма ALTER TABLE](database_labs/structure_forms.py) добавляет, удаляет и переименовывает столбцы, переименовывает таблицы, меняет типы и управляет ограничениями CHECK, NOT NULL, UNIQUE и FOREIGN KEY. PostgreSQL применяет каждое изменение в транзакции.
- [Конструкторы запросов](database_labs/query_forms.py) покрывают выбор столбцов, WHERE, ORDER BY, GROUP BY, агрегаты и HAVING. Поиск поддерживает LIKE и операторы `~`, `~*`, `!~`, `!~*`. Отдельные формы показывают строковые функции и результаты INNER, LEFT, RIGHT и FULL JOIN.

## Что показать на защите

1. В ALTER TABLE добавьте в `models` столбец `version` типа `integer`, переименуйте его в `revision`, смените тип на `text` и удалите этот столбец. Столбец появился и исчез из списка полей SELECT.
2. В SELECT выберите `experiments`, группировку по `dataset_id`, агрегат COUNT без поля, HAVING `>= 2` и сортировку по `aggregate_value`. После загрузки примеров получите две группы по три эксперимента.
3. В поиске выберите `experiments.title` и LIKE с шаблоном `Блог%`. Получите три записи. Повторите с `~*` и шаблоном `^блог`.
4. Для `experiments.title` запустите UPPER и SUBSTRING. Сравните исходное и преобразованное значения в соседних столбцах.
5. В мастере JOIN соедините `datasets.id` слева с `experiments.dataset_id` справа. У INNER JOIN шесть строк. LEFT JOIN добавит датасет **Сообщения поддержки** без эксперимента. Проверьте фильтрацию и сортировку результата.
